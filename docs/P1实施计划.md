# P1：许知宁与稳定聊天底座

目标：不改变现有 NapCat 连接，将原型升级为配置化角色、限定用户、近期上下文持久化及可靠回执处理。

按顺序单线程实施：
- [x] 先写测试：角色、存储重启、隔离、额度、去重、回执失败与排队；运行确认失败。
- [x] 增加 app/persona.py、app/store.py、app/transport.py，角色存 characters/xu_zhining.md。
- [x] 重构 bot.py：保留 private_text 兼容入口；独立接收回执、用户队列和受限模型并发。
- [x] 运行离线测试；模拟 OneBot 完整事件往返，验证发送结果。
- [x] 增加 scripts/bot.ps1 启停状态和非敏感说明。凭据和授权号码仅本机 .env。
- [x] 测试通过后只重启本项目聊天进程，NapCat 保持在线；观察连接与真实模型生成。
- [ ] 主人确认新版本真实QQ回复。代码版本管理结果以Git及本轮提交回执为准。

边界：上下文保留最近12条已确认送达消息，存储30天后清理；未送达及不确定回复不入上下文，不自动重发；未实现长期事实记忆、摘要、关系成长、语音。
SQLite数据、队列状态和每日额度可重启保留；内存中的未完成队列在重启后标记 interrupted，不承诺跨重启自动续跑。单用户队列满时显式繁忙提示，不静默忽略。所有服务仅本机。
