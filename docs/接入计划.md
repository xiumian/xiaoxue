# 第一阶段：接入验证

目标：QQ 私聊消息经独立服务调用 DeepSeek 后回复，不创建聊天界面。

已确定：Windows 本地先跑；Python 3.12 独立虚拟环境；凭据仅本机 .env，禁止进入日志、文档和 Git。

本轮：配置私密凭据、创建环境、验证 API 鉴权、核验 NapCat 官方接入文档。
后续：部署独立 NapCat 运行目录（D盘），由主人扫码小号；本机 OneBot 连接必须带随机令牌，仅监听回环地址；完成真实私聊收发后再加上下文与记忆。

验收：模型服务鉴权成功不代表聊天调用成功；OneBot连接成功不代表QQ往返成功；逐项保留脱敏结果。
不做：修改现有QQ登录、开放公网端口、自动执行聊天消息中的命令、群聊、语音、App。
